# 采集合集与搜索

两类"发现候选 → 批量采集"的入口:合集展开、条件搜索。含充电专属视频。

相关:[[采集模型]]、[[批量采集 UP 主视频]]

## 合集批量

视频属于合集(ugc_season)时,一键展开全集:

```bash
# BV 号(须已采过)/ 合集 id / 合集页链接,三种都认
pnpm cli collect season BV1xxxxxx --dry-run    # 先只列计划(missing 清单),不建任务
pnpm cli collect season BV1xxxxxxx             # 展开全量,未采的批量建任务(server 串行执行)
```

- **popup 合集卡**:在合集视频页弹出,`seasons_archives_list` 全量分页列出全集,勾选批量采集上报
- 标签侧:合集视频自动挂 **season 档标签(只读,实时读 `extra.ugc_season.title`)**,见 [[标签体系]]

## 搜索批量(B 站)

```bash
# 关键词搜候选(不入库)
pnpm cli collect search "sqlite 性能" --page 1 --order pubdate --tid <分区id>

# 条件检索:关键词(+分区)多页搜索,按发布时间 / UP 粉丝数过滤候选
# 粉丝数优先读 creators 表缓存,miss 实时查
pnpm cli collect find "数据库选型"          # 返回过滤后的候选列表
```

确认后对候选 BV 号批量 `collect subtitle` 或界面勾选。

## 充电专属视频

充电专属视频正常采集,入库自动带付费标记:

```bash
pnpm cli videos list --paid          # 圈出付费视频
```

## 搜索结果判重

批量提交前先看哪些已入库:

```bash
pnpm cli collect dedupe BV1aaa BV1bbb    # collected / missing 两组
```
