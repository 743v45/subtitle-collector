# 采集单个视频

最常用的两个动作:打开页面就采(被动)、缺什么补什么(手动)。

相关:[[采集模型]]、[[批量采集 UP 主视频]]

## 被动采集(零操作)

浏览器打开任意 B 站视频页,扩展自动抽取该视频的字幕元信息并入库。日常刷视频即是采集。

## 手动补采

某个视频被动没采到(当时扩展没连上 / 视频刚发)时:

```bash
pnpm cli collect subtitle BV1xxxxxx
# YouTube / 抖音视频带 --source:
pnpm cli collect subtitle dQw4w9WgXcQ --source youtube
pnpm cli collect subtitle 7345678901234567890 --source douyin   # 19 位 aweme_id
```

| 选项 | 说明 |
|---|---|
| `--source <src>` | 平台,默认 `bilibili`;YouTube 用 `youtube`,抖音用 `douyin`(vid 为 19 位 aweme_id) |
| `--client <id>` | 指定扩展 client_id,缺省取第一个在线客户端 |
| `--timeout <ms>` | 等扩展回执超时,默认 180000 |

## 抖音链接形态与采集方式

抖音侧只做**主动采集**(无 B 站式浏览被动入库)——server 派任务给扩展,扩展后台开 tab 导航到视频页,在页面上下文里取数(抖音接口带页面签名,server 无法直连)。提交入口三处:CLI `collect subtitle <aweme_id> --source douyin`、web 采集页粘贴、手机分享(见 [[手机采集]])。

粘贴给 server / 手机 app 的链接四形态都认(2026-08-29 起):

| 形态 | 例子 | 处理 |
|---|---|---|
| 分享短链 | `https://v.douyin.com/xxxxxx/` | server 跟随 302 展开成标准页再解析(手机分享文案里的就是它) |
| 标准视频页 | `https://www.douyin.com/video/<19位id>` | 直接解析 |
| modal_id 参数 | `https://www.douyin.com/jingxuan?modal_id=<19位id>` | 分享落地形态,归一到标准页 |
| 图集页 | `https://www.douyin.com/note/<19位id>` | 可提交;图集无视频轨,采集回执 `not_video` → 任务失败(「图文/图集,无视频轨」) |

popup 在抖音视频页:显示抖音平台头 + 视频信息卡(页面数据聚合展示)与库内同步状态;抖音不做页面被动上报(底栏「上报」按钮对抖音页不生效),也不弹 UP/频道类批量卡——博主批量走 web 采集页入口,见 [[批量采集 UP 主视频]]。

## 刷新已采视频

字幕更新了(UP 补传 / 平台生成 AI 字幕)想重采:

- **web**:视频详情页「刷新字幕」按钮,或采集页 / 历史页任务行的刷新图标
- 幂等:内容没变零新增,任务行显示「已刷新:新增 X 版 / 无新增」

## 判断视频是否已入库

```bash
pnpm cli collect dedupe BV1aaa BV1bbb BV1ccc --source bilibili
# 返回 collected / missing 两组
```

批量勾选前先 dedupe,避免对已采视频重复建任务(勾了也不怕,会走刷新幂等)。
