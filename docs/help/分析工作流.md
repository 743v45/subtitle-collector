# 分析工作流

项目的最终产出不是字幕本身,是三种文字资产。本页是从原料到产物的手动闭环。

相关:[[导出分析原料包]](第一步的原料)、[README 分析产物规范](../../README.md)(落盘规范锚点)

## 三类产物

| 类型 | 问题 | 原料 |
|---|---|---|
| **观点汇总** | 某技术话题,多个 UP 主怎么看(含分歧与共识) | 按搜索主题 / 标签打包的 bundle |
| **面试题库** | 面试内容整理:题目 + 考点 + 参考答案 | 面试相关视频的 bundle |
| **理念整理** | 某 UP 主系列视频的核心理念 / 方法论提炼 | 按 UP 主打包的 bundle |

## 闭环五步

```bash
# 1. 选过滤器,导出原料包
pnpm cli export bundle --creator "某UP"

# 2. 开一个 Claude Code 会话,指向原料目录
#    (读 ANALYZE.md + 按需读 videos/*.txt,不必整包读)

# 3. 会话内按产物类型分析提炼

# 4. 产物落盘 analysis/<主题>/

# 5. 想归档到知识库的结论,走 taevasidian 的 /wiki 流程
```

## 当前状态与纪律(重要)

- 分析在 **Claude Code 会话**中完成,系统只负责原料导出与产物落盘规范;内置 AI pipeline(一条命令自动分析)是远期项,手动流程跑顺前不评估
- **消费端冻结政策**(2026-08-22 拷问确认):本闭环(bundle 导出 → 会话分析 → `analysis/<主题>/` 落盘)跑通前,**不新增采集侧能力**;落盘规范以 [README](../../README.md)「分析产物规范」条目为准
- 评论采集不在数据源内(远期),当前分析只用视频 / 字幕内容

> [!warning] 别绕路
> 探索性分析可以会话内临时跑,但**可复用的批量编排应沉淀为 CLI / scripts 代码**(CLAUDE.md §8);临时方案跑顺后回头固化。
