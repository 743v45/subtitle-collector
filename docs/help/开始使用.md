# 开始使用

从零把采集链路跑起来:扩展 → server → web 三端。约 10 分钟。

相关:[[采集模型]](跑通后先读它)、[[环境变量]]、[[排错]]

## 前置

- **Node 22**(见 [.nvmrc](../../.nvmrc))
- **pnpm 9.15.4**(推荐 `corepack enable` 自动锁版)

## 1. 安装依赖

```bash
pnpm install
```

根目录一次到位,含 ws / better-sqlite3 / puppeteer。

## 2. 启动本地服务端

```bash
pnpm dev:server          # 监听 http://127.0.0.1:21527
```

> [!tip] 一键多终端
> `pnpm dev`(= `turbo dev`)并行起 server + web + 扩展三端 dev server。首次建议还是分步跑,便于定位问题。

## 3. 构建前端与扩展

```bash
pnpm build:web           # 产物写入 collector-server/public,由 server 托管
pnpm build:ext           # 产物到 apps/subtitle-collector/dist/
```

## 4. 加载扩展到 Chrome

1. 打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 「加载已解压的扩展程序」→ 选择 `apps/subtitle-collector/dist`

> [!warning] 端口不能漂移
> 扩展 dev server 端口在 [vite.config.ts](../../apps/subtitle-collector/vite.config.ts) 用 `strictPort` 钉死为 **5174**(web 是 5173)。改了会触发 CRXJS popup 闪烁死循环,详见 [[排错]]。

## 5. 验证链路

浏览器打开任意 B 站视频页,popup 显示「已连接 ✓」即通。两个条件:

1. collector-server 已在 `127.0.0.1:21527` 运行
2. popup 激活的 server 是默认 `ws://127.0.0.1:21527/ext`(未设 `COLLECTOR_TOKEN` 时开箱即连)

再跑一条只读命令确认数据面:

```bash
pnpm cli collect search "数据库"     # 关键词搜视频,返回候选(不入库)
pnpm cli videos list                 # 看库里有什么
```

打开 `http://127.0.0.1:21527` 就是 web 界面(视频库 / 采集页 / 任务历史)。
