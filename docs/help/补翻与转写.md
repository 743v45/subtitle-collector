# 补翻与转写

web 补翻页(侧栏「工作流 → 补翻」)干两件事:**补翻**(给无中文轨的视频写回一条 `zh-manual` 翻译轨)与 **ASR 转写兜底**(给无字幕视频批量转写入库)。分别是 CLI `translate` 三步与 `asr backfill` 的 web 形态,细节页见 [[补翻中文字幕]]、[[无字幕视频处理]]。

## 补翻工作台三步

1. **pending 清单**:打开补翻页,列表即待补翻视频(无中文轨、有其他语言轨,带源语言与行数);可按平台 / 源语言筛选、翻页
2. **取原文翻译**:点行进入双栏工作台——左栏「行号 + 原文」只读,把原文交给会话内大模型翻译(CLI 形态是 `translate source` 落盘中转,web 里复制即可)
3. **写回**:右栏逐行粘贴/输入译文(可多行粘贴,也可「从文件载入」整份文本)——实时行数对账,**译文行数 = 原文行数才可写回**(不符标红;空行 = 该行保留占位),点「写回 zh-manual 轨」

写回后时间轴从源轨拷贝、默认轨变中文(export/检索/bundle 自动受益),规则见 [[补翻中文字幕]]。server 拒绝时 400 文案原样透出(含 expected/got 行数,直接对账)。

## ASR 转写兜底卡

补翻页顶部「无字幕转写兜底(ASR)」卡,把 `no-subtitle` 标记的视频批量转写入库:

1. 选平台(B 站 / 抖音)、每轮条数(1–50,默认 5)、时长上限秒(留空不限)
2. 点「**预览圈定**」——dry_run 同步直答,只列将转写的视频清单,不建任务
3. 点「**提交转写**」——建后台任务,下方进度卡实时轮询,可取消;跑完弹系统通知
4. 转写成功自动摘 `no-subtitle` 标、写回 `asr-zh-<引擎>` 轨;重跑自动只剩未完成的(断点续跑)

B 站未配 cookie 不拦截提交:server 回包带黄色警示(无登录态转写必然 need_login),是否继续自行裁量。转写链路与失败分类(need_login / video_too_large 等)见 [[无字幕视频处理]]。

## 转写服务配置(三个环境变量)

转写由 collector-server 进程执行,调用本机 fireredasr 服务(OpenAI 兼容;`~/Local/fireredasr-ui`,`./run.sh start`):

| 变量 | 默认值 | 说明 |
|---|---|---|
| `COLLECTOR_ASR_BASE_URL` | `http://127.0.0.1:5079` | fireredasr 服务地址 |
| `COLLECTOR_BILI_COOKIE_FILE` | 空 | B 站 Cookie 文件路径(文本原样作 Cookie 头);**B 站转写必配**,抖音零 cookie |
| `COLLECTOR_ASR_ENGINE` | `fireredasr-aed-l` | 引擎标记,兼定轨名 `asr-zh-<引擎>` |

- **server 跑在宿主机**(dev / `pnpm dev:server`):默认地址开箱即用,cookie 用 env 指到本地导出的文本文件
- **server 跑在容器**(docker compose):容器里的 `127.0.0.1` 是容器自身,`COLLECTOR_ASR_BASE_URL` 要改成 `http://host.docker.internal:5079` 才能访问宿主机的 fireredasr(compose 的 `environment` 段加三个变量);cookie 文件 `docker cp` 进容器后把 `COLLECTOR_BILI_COOKIE_FILE` 指到容器内路径

## 最近任务

补翻页清单下方是「最近任务」台账(ASR 转写与条件采集共用),行内展开看进度卡;提交成功后切走页面也能回来找到任务。

## 与 CLI 的对应

| web | CLI |
|---|---|
| pending 清单 | `pnpm cli translate pending`(筛选/排序同源) |
| 工作台(原文 / 译文 / 写回) | `translate source` + `translate fill` |
| ASR 卡「预览圈定」 | `asr backfill --dry-run --size N` |
| ASR 卡「提交转写」 | `asr backfill --size N [--max-duration 秒]` |

CLI 侧 cookie 也可每次用 `--cookie-file` 指定(不经 env)、服务地址用 `--asr-url`,见 [[无字幕视频处理]]。
