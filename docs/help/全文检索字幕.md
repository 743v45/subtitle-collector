# 全文检索字幕

`sub search`:搜字幕正文,带时间戳定位到片段。"那句'事务隔离'是哪个视频第几分钟说的"这类问题的答案。

相关:[[检索视频库]]、[[导出字幕与视频]]

## 基本

```bash
pnpm cli sub search "事务隔离"
```

输出:命中视频 + 片段(时间戳 + 原文),每视频默认最多 3 段、全局上限 30 段。

## 常用选项

| 选项 | 说明 |
|---|---|
| `--ctx <秒>` | 命中点上下文时间窗,默认 10 |
| `--regex` | 关键词当 JavaScript 正则源串 |
| `--case-sensitive` | 区分大小写(默认不区分) |
| `--all-tracks` | 搜所有字幕轨(默认只搜默认轨:CC中文 > AI中文 > 英文 > 其他) |
| `--creator <name>` | UP 名模糊,视频预筛 |
| `--source <src>` / `--tid <id>` | 平台 / 分区预筛 |
| `--plain` | 片段去时间戳只留纯文本 |
| `--full` `--full-format srt` | 直接回整条字幕(txt/srt/vtt/json) |

## 例子

```bash
# 找谁讲过 MVCC,看前后 20 秒上下文
pnpm cli sub search "MVCC" --ctx 20

# 正则:数据库 OR 存储
pnpm cli sub search "数据库|存储" --regex

# 搜某 UP 所有轨里的 "cache"
pnpm cli sub search "cache" --creator "某UP" --all-tracks

# 命中后直接导出该视频完整字幕
pnpm cli export subtitle bilibili BV1xxxxxx --track zh-Hans -o out.srt
```
