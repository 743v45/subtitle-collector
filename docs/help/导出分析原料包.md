# 导出分析原料包

`export bundle`:把一批视频的元信息 + 字幕打包成一个自包含的分析原料目录,喂给 [[分析工作流]]。

相关:[[检索视频库]](过滤器同源)、[[分析工作流]]

## 用法

过滤器与 `videos list` 完全一致,无分页——命中多少打包多少:

```bash
# 按 UP 主打包
pnpm cli export bundle --creator "某UP"

# 按标签打包
pnpm cli export bundle --tag "数据库"

# 任意组合过滤
pnpm cli export bundle --source bilibili --since 2026-07-01 --track-type 2
```

## 产物结构

```
<输出目录>/
├── manifest.json     # 批次元信息:过滤器、视频清单、轨道/版本选择
├── videos/
│   └── *.txt         # 一视频一文件,正文为「[分:秒] 字幕」行格式
└── ANALYZE.md        # 给分析会话的说明(怎么读这批原料)
```

正文行格式示例:

```
[03:12] 这里我们看一下事务隔离级别
[03:18] 首先是读已提交
```

## 为什么是这个格式

- `[分:秒]` 前缀让分析时能**回溯时间点**(引用原视频第几分几秒)
- 一视频一 txt,分析会话按需读单文件,不用整包塞上下文
- manifest.json 记录批次构成,产物可追溯

导出后接着走 [[分析工作流]]。
