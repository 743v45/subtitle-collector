# 客户端与任务派发

"客户端" = 一个装了采集扩展的浏览器。多机采集、任务调度、命名管理都在这页。

相关:[[采集模型]]、[[环境变量]]

## 列出客户端

```bash
pnpm cli clients list
# 含离线客户端(DB 注册表合并在线态),显示名字、在线/离线时长
```

server 重启不丢注册表,旧 client_id 会留存。

## 仅上报开关(任务派发管控)

某台机器只想贡献数据、不想被派活(比如日常用的笔记本):

```bash
pnpm cli clients task-dispatch <clientId> off    # 关:仅上报状态,调度器不派任务,保持连接
pnpm cli clients task-dispatch <clientId> on     # 开:恢复接单
```

- **popup / options 里也有此开关**
- 多客户端时,任务派给开着的机器;**全关则任务留 pending**(排错见 [[排错]])
- 另有 `reporting` 开关(上报总开关,日常不动):
  ```bash
  pnpm cli clients reporting <clientId> off
  ```

## 客户端命名

- **popup 底栏「改名」**:id 不变,名字本地落盘并经 hello/client-name-state 同步 server 持久化,清空保存即删除
- `clients list` 显示名字

## 登录态(判因)

`clients list` 与 web 客户端页每台客户端带 **B 站 / YouTube 双平台登录态**(离线也留存,显示最后上报的状态;null = 旧版扩展未上报过,升级扩展后出现)。

| 平台 | 未登录的后果 | 恢复方式 |
|---|---|---|
| B 站 | 充电视频 AI 字幕接口返回空——派给该客户端的批量采集会**整批 no_subtitle** | 在该浏览器登录 B 站,自动恢复上报 |
| YouTube | 年龄限制视频播不了、字幕 pot 受限加重——批量 **no_subtitle / pot_limited** 的判因依据 | 在该浏览器登录 YouTube,自动恢复上报 |

- popup 平台头也按当前平台显示登录徽章(B 站可点切昵称/UID;YouTube 无账号字段只显已/未登录)
- 批量采集整批 no_subtitle 时,先看这里判因:未登录 → 去浏览器登录;已登录 → 见 [[排错]] 与 [[无字幕视频处理]]

## 下发命令并等回执

```bash
pnpm cli clients command <clientId> <action> [--op <op>] [--url <url>] [--vid <vid>] [--timeout <ms>]
```

wait 恒真,`--timeout` 控制上限。

## 排序

`clients list --sort <key> [--desc=false]`:最近活跃 / 首次见到 / 名字,默认最近活跃在前。
