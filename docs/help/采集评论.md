# 采集评论

把单个 B 站视频的评论区（根评论 + 楼中楼全量）采集成完整分析树入库；之后 `export bundle` 自动携带评论原料，分析会话可回答「观众怎么看」。命令三件套：`comments collect` 采集入库 / `comments verify` 完整性校验 / `comments tree` 树形查看。

相关:[[采集模型]]、[[导出分析原料包]]、[[无字幕视频处理]](同类直连型入口)

> 下文命令在 `apps/collector-server` 目录执行(`npx tsx src/cli/main.ts`;全局选项 `--db/--server/--token/--format` 放子命令前)。

## 0. 前置

- **视频已入库**:评论挂在视频行上——库内没有该视频时先采视频([[采集单个视频]]),否则 collect 退 5 `video not found`
- **server 在跑**:`collect` 的定位与写库走 server HTTP(本地默认 `http://127.0.0.1:21527`;写生产库加全局 `--server <url> --token <t>`)
- **B 站 cookie(必配)**:评论采集必须登录态(wbi 签名前置 nav 接口匿名恒 -101)

```bash
node scripts/bili-cookie-from-chrome.mjs --refresh   # 从 Chrome 拷 cookie → ~/Local/collector-secrets/bili-cookie.txt
```

前置条件:Chrome 装在默认路径、B 站登录态在 Default profile。SESSDATA 约 1 个月有效;采集中报 `-101`/`need_login` 时重跑本脚本(加 `--refresh`)。也可 `--cookie-file <path>` 或环境变量 `COLLECTOR_BILI_COOKIE_FILE` 指定其他 cookie 文件。

## 1. dry-run 试跑(不写库)

```bash
npx tsx src/cli/main.ts comments collect --bvid <BV号> --dry-run
```

取数、解析、stderr 日志照常,但不调写库接口。回执 `dry_run:true`,store 段变为 `would_requests`/`rows` 预估计数。首次对某视频采集前先跑一遍,确认 cookie 有效、评论区规模可控。

## 2. 全量采集

```bash
npx tsx src/cli/main.ts comments collect --bvid <BV号> --mode full
```

- `--mode` 三值:`full` 时间序游标遍历全量 + 删除对账;`incremental` 只追新;`auto`(默认)按库内行数分流——0 行走 full、否则 incremental。**首次采集直接省略 `--mode` 即可**(auto 等价 full)
- 置顶评论、楼中楼(按实时条数翻全)、成员快照、IP 属地照常入库
- 回执(stdout JSON):`fetched`(roots/floors/total)、`store`(inserted/updated)、`verify`(内嵌校验)、`partial`(true 时带 `partial_reason` 说明判停原因)

大视频先小样本试水:`--max-pages 2`(主列表页数上限);控制单轮请求总量用 `--max-requests`(默认 600,用尽判停 `request_budget`)。

## 3. verify 核对

```bash
npx tsx src/cli/main.ts --format json comments verify --bvid <BV号>
```

本地只读校验,建议 `--format json`(嵌套回执 table 形态不可读)。重点字段:

| 字段 | 怎么读 |
|---|---|
| `coverage.ratio` | 楼中楼覆盖率(实采/分母;分母=楼中楼接口实时条数,缺失时回落根行 rcount)。≥0.98 视为健康 |
| `integrity.root_count_gap` | 库内活跃总量与 B 站总量哨兵的缺口(R9)。非 0 时带上 `--stat-reply <稿件页评论总量>` 复跑对账 |
| `counts.missing_candidates` / `missing_confirmed` | 缺席一轮完整全量的根评论数 / 连续两轮缺席确认缺失数(确认行不再导出) |
| `integrity.orphan_floor` / `dangling_parent` / `dangling_dialog` | 根缺失的楼层 / 父评论悬空 / 「回复 @」指向缺失——删除建模的正常产物,少量属预期,持续增长才需关注 |

`--stat-reply <n>` 是外部哨兵(B 站稿件页 stat.reply 总量),给了才启用 R9 规模对账,缺省跳过。

## 4. 日常增量

```bash
npx tsx src/cli/main.ts comments collect --bvid <BV号> --refresh-roots 50
```

- 增量按发布时间水位只追新评论 + 翻全本轮新见根的楼中楼
- **老楼的新回复默认不追**(老根不在时间序窗口内);`--refresh-roots 50` 让库内点赞 top 50 根强制重翻楼中楼补新回复
- 删除对账只在 full 轮发生(连续两轮完整全量缺席才确认缺失,增量轮不动水位)

## 5. 批量采集

```bash
npx tsx src/cli/main.ts comments collect --bvid-file <文件路径>
```

文件每行一个 BV 号(`#` 注释),串行执行、视频间固定 5s 间隔;单个视频失败不阻断后续,回执为 per-video 数组。与 `--bvid`/`--aid` 互斥。

## 6. 查看与消费

```bash
npx tsx src/cli/main.ts comments tree --bvid <BV号> --limit 20   # 树形缩进速览点赞前 20 根
```

- `tree`/`verify` 是 **DB 只读**:全局 `--server` 传了也会被忽略(stderr 一行警告)——查生产库先做快照再 `--db <快照绝对路径>`(双库说明见 [[检索视频库]])
- `export bundle` 不需要新参数:库内有评论的视频自动导出 `comments/<BV号>.md` 正文 + manifest `comments` 摘要,格式见 [[导出分析原料包]]

## 常见报错

| 现象 | 处置 |
|---|---|
| 退出码 2(ARGS) | 参数错:`--bvid`/`--aid` 双缺、cookie 缺失或不可读、`--mode` 非法值——按报错信息补参 |
| 退出码 3 | server 不可达:先起 server(`node scripts/run-collector-server.mjs`)或核对 `--server` |
| 退出码 5 `video not found` | 视频不在库:先采视频再采评论 |
| `need_login`(partial) | cookie 失效:`node scripts/bili-cookie-from-chrome.mjs --refresh` 后重跑 |
| `risk_control` 类 partial(-352/-412 等) | 三档退避后仍失败:换时段/降频再跑;已入库部分不受影响(行级幂等,重跑安全) |
| `comments_disabled` | 评论区已关闭的正常终态(total=0,不是错误) |

## 参数速查(comments collect)

| 参数 | 默认 | 说明 |
|---|---|---|
| `--bvid <bvid>` | 与 `--aid` 至少其一 | 目标视频 BV 号(与 --aid 二选一或同给做交叉校验;与 --bvid-file 互斥) |
| `--aid <aid>` | — | 目标视频 av 号(oid;单独给时经 view 接口回查 bvid) |
| `--bvid-file <path>` | — | 批量模式:文件每行一个 BV(# 注释),串行+5s 间隔,失败不阻断(与 --bvid/--aid 互斥) |
| `--mode <mode>` | `auto` | auto(库内 rows==0→full / >0→incremental)\|full(全量)\|incremental(水位追新) |
| `--sort <sort>` | `time` | hot(仅 full 首页 mode=3 快照)\|time(默认,纯时间序) |
| `--max-pages <n>` | `0` | 主列表页数上限(0=不限;触顶→partial max_pages_cap) |
| `--max-floor-pages <n>` | `0` | 单根楼中楼页数上限(0=不限;触顶→partial floor_pages_cap) |
| `--refresh-roots <n>` | `0` | 增量轮附带强制重翻点赞 top-N 根(本轮所见根域,0=关闭) |
| `--max-requests <n>` | `600` | 单视频 B 站请求预算(用尽→partial request_budget) |
| `--page-interval-ms <n>` | `2000` | 页间隔基数 ms(±30% 抖动) |
| `--batch-size <n>` | `200` | ingest 批大小 |
| `--dry-run` | off | 取数+解析+计数照常,不写库(回执 store 段为 would_requests/rows) |
| `--cookie-file <path>` | `$COLLECTOR_BILI_COOKIE_FILE` | B 站 Cookie 文件(文本原样作 Cookie 头;必配) |

`tree` 另有 `--limit <n>`(只显示点赞前 N 根,0=不限);`verify` 另有 `--stat-reply <n>`(外部总量哨兵,启用 R9 规模对账)。
