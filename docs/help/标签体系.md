# 标签体系

六档标签:四种落表(manual/batch/ai/system)+ 两种实时(bili/season)。档位决定"谁有权打/摘这个标"。

相关:[[检索视频库]]、[[无字幕视频处理]]

## 六档一览

| 档位 | 存储 | 谁来打 | 典型 |
|---|---|---|---|
| `manual` | 落表 | 人工 | 自定义主题标 |
| `batch` | 落表 | 批量操作 | 批量采集时打的标 |
| `ai` | 落表 | AI(分析流程) | 分析产物打的标 |
| `system` | 落表 | 采集链路自动 | `no-subtitle`(无字幕圈定,见 [[无字幕视频处理]]) |
| `bili` | 视频 extra 自带 | 平台 | B 站视频原生标签 |
| `season` | 实时读 `extra.ugc_season.title` | 平台(只读) | 合集名 |

档位间有 `tag_priority` 可调(六档展示优先序,web 设置页或 CLI `settings set tag-priority --order manual,batch,bili,season,ai,system`,六档缺一不可);按档位过滤 / 聚合(标签榜)。

## UP 主分类治理(2026-10-05)

`categories` 组管理 UP 主(创作者)分类值域(agent/human 两槽位共用一套分类;给 UP 打分类在 web 创作者页,CLI 负责值域维护):

```bash
pnpm cli categories list                                  # 全量列表(含 creator_count 引用计数)
pnpm cli categories add AI 基础                            # 新建(重名 409 → 退 1)
pnpm cli categories update 3 --name AI --sort-order 2      # 改名/排序(至少传一键;不存在 → 退 5)
pnpm cli categories delete 7                               # 删除(引用它的 UP 两槽位自动置 NULL)
```

分类 id 取 `categories list` 输出的 `id` 列;`categories list` 常配 `creators list --category <名>` 用(先看值域再筛 UP)。

## 命令

```bash
# 榜单与查询
pnpm cli tags list --scope manual --topN 20
pnpm cli tags list --q "性能" --sort count

# 打标 / 摘标
pnpm cli tags apply BV1xxx BV1yyy --scope manual
pnpm cli tags remove BV1xxx --scope batch      # 省略 --scope 删全档

# 标签库纠错(打错标签改名 / 删标重建,2026-10-05)
pnpm cli tags rename 7 --name 新名   # 已有打标关系自动跟随新名;撞已有名 409 → 退 1
pnpm cli tags delete 8               # 删标签含全部档位关系;不存在 → 退 5
```

`tags list` 参数:`--scope`(manual/batch/ai/system 档位过滤)、`--source`(平台,计数只算该平台)、`--sort`(计数 / 名字 / 建标时间)。

`tags rename` / `tags delete` 的 `<id>` 是标签库 id(`tags list` 输出的 `id` 列,不是视频 id);两者都走 server HTTP,需配 `--server` / `--token`(写生产库时)。

## 界面侧

- web 视频库:**多标签下拉多选**筛选 + 标签档位过滤
- 标签榜:计数 / 名字 / 建标时间排序(全端点统一排序)
