# 检索视频库

两层检索:web 界面(浏览)与 `videos list`(脚本 / 精确过滤)。

相关:[[全文检索字幕]](搜字幕正文)、[[标签体系]]

## web 界面

打开 `http://127.0.0.1:21527`,视频库为**列表布局**(一行一视频:平台图标+标题 / 创作者 / 播放 / 时长 / 轨道数 / 发布时间 / 标签列,窄屏自动折叠次要列;分区不再单列,去视频详情页看)。

- 多维筛选:关键词、**字幕正文**、多标签下拉多选、标签档位、分区、时间、时长/播放区间;平台筛选(B 站 / YouTube / 抖音,标题行平台图标区分)
- **全部筛选条件走 URL query**:刷新 / 分享链接即还原;视频详情的轨/版本选择也进 URL
- 原站外链:标题旁 ↗ 开原视频页,UP 名 ↗ 开空间页/频道页
- **标签列折叠**:一行默认只显前 2 个标签,「+N」展开本行全部、再点「收起」折回(仅当前行瞬态,不进 URL)
- UP 主 / 创作者分类管理:一套共享分类值,Agent 与人工在 UP 主两个槽位分开打标;创作者页可按槽位(全部 / Agent / 人工)筛选,数量列点击跳转按分类过滤

## 视频详情页

- **字幕复制 / 下载合并为两下拉**:「复制 ▾」「下载 ▾」各展开 SRT / VTT / TXT 三格式(原六个平铺按钮收进下拉);只有一个字幕版本时不显示版本切换器
- **评论区入口(仅 B 站视频)**:元信息区「评论 N」按钮展开只读评论树,详见 [[采集评论]]

## 创作者页:批量分类与资料刷新

- **批量分类**:创作者列表勾选多行(表头勾选框全选本页)→ 表格上方出现批量操作条 → 分别给 Agent / 人工两槽位选「— 不变 — / — 清除 — / 具体分类」,点应用即生效(成功提示更新数量并清空勾选;失败勾选保留便于重试)
- **刷新资料**(仅 B 站创作者):列表行内或详情页「刷新资料」按钮重拉空间资料(昵称 / 头像 / 签名 / 粉丝数等),成功后列表自动刷新;字段缺失不会清空既有资料
- **分类管理页前缀分组**:分类名按第一个 `-` 前缀分组展示(如「编程-前端」归「编程」组、组内只显后缀,悬停看全名);无 `-` 的归「其他」组恒排最后——分组纯展示,分类的增删改不受影响

## CLI:`videos list`

```bash
pnpm cli videos list --size 20
pnpm cli videos list --creator "某UP" --has-subtitle
pnpm cli videos list --tag no-subtitle --source bilibili
pnpm cli videos list --subtitle-q "事务隔离" --since 2026-08-01
pnpm cli videos list --tag 游戏 --tag-source manual
pnpm cli videos list --creator-uid 12345 --date-field published_at --since 2026-01-01
```

常用过滤项:

| 选项 | 说明 |
|---|---|
| `--q <text>` | 标题 / UP 名模糊 |
| `--creator <name>` | UP 名模糊 |
| `--creator-id <id>` / `--creator-uid <uid>` | UP 精确(库内 id / 平台 uid,如 B 站 mid 直查免换算) |
| `--source <src>` | 平台精确(bilibili / youtube / douyin) |
| `--tag <tag>` | 标签名模糊 |
| `--tags <csv>` | 多标签精确,逗号分隔,AND 语义(全部命中才算) |
| `--tag-source <csv>` | 标签档位过滤(manual / batch / ai / system / bili / season 子集):配 `--tag`/`--tags` 收窄匹配档位;单独传=该档位有任一标签 |
| `--subtitle-q <text>` | **字幕正文**关键词(命中 subtitle_versions.payload) |
| `--lang <lang>` | 字幕语言模糊(`zh` 命中 `zh-Hans`) |
| `--track-type <type>` | 字幕轨类型:1=AI 2=CC 3=翻译轨 |
| `--has-subtitle` / `--paid` | 仅含字幕 / 仅付费视频 |
| `--since` / `--until` | 时间过滤(Unix 秒/毫秒 或 ISO8601) |
| `--date-field <field>` | 上两行比对的列:`first_seen`(缺省,入库时间)/ `published_at`(发布时间) |

非法值处理:枚举类参数(`--sort` / `--tag-source` / `--date-field`)传非法值直接报错退 2;数字/时间非法同样 ARGS 报错。

## 排序(全端点统一)

```bash
pnpm cli videos list --sort first_seen --desc=false
```

排序键:first_seen / 发布时间 / 标题 / 时长 / 播放量 / updated_at;`--desc=false` 升序。非法键 HTTP 400 / CLI 退 2。NULL 值恒排尾。

## CLI:`creators list/get`(UP 主查询)

查库里已知的 UP 主(创作者)资料:粉丝数排序看大盘、按分类筛、回填任务前查缺资料 UP 清单。

```bash
pnpm cli creators list --source bilibili --sort fans --size 20
pnpm cli creators list --category AI --scope agent
pnpm cli creators get 42
```

常用选项:

| 选项 | 说明 |
|---|---|
| `--q <text>` | UP 名 / 平台 uid 模糊 |
| `--category <name>` | 分类名精确(配 `--scope` 选匹配槽位;省略两槽位任一命中) |
| `--scope <s>` | `agent`(Agent 打标) / `human`(人工打标);单独传=该槽位已打标的 UP |
| `--source <src>` | 平台精确(bilibili / youtube / douyin) |
| `--page <n>` / `--size <n>` | 翻页(每页默认 20,上限 100) |
| `--sort <key>` | `first_seen`(缺省) / `fans` / `video_count` / `following` / `level` / `updated_at` / `name` |
| `--desc [value]` | 缺省降序,升序 `--desc=false` |

`creators get <id>` 取单个 UP 主详情(简介 sign / 等级 level / 性别 / 认证 / 粉丝 / 关注 + 分类),`<id>` 是**库内自增 id**(列表输出的 `id` 列,不是平台 uid)。

与 [[无字幕视频处理]] 配合:回填转写前先 `creators list` 盘点缺资料 UP,优先补 `collect upper-info`。
## 看板页(Top10 + 覆盖率)

web「看板」页(数字总览 + 分组聚合榜)两个增强:

- **Top10 + 其他**:「按分区」聚合超过 10 条时,第 11 名起余量聚合为「其他(M 个分区 · K 个视频)」一行,不再无限拉长列表;其余聚合维度(创作者/语言/轨类型/标签/平台)不收 Top10
- **已分区覆盖率**:按分区聚合时数字卡下方显示「已分区覆盖率 N%」徽标 = 有分区信息的视频占比——一眼看出分区元数据缺口
- 采集时间范围某端缺失时显「最早未知 / 最晚未知」,不再出现裸 `-`

## 变更日志页(标识内链)

web「变更日志」页按 时间 / 类型 / 平台 筛选字段级变更历史;**标识列可点**:视频变更的 BV 号点击直达视频详情,UP 变更的标识点击直达创作者详情(旧行缺定位字段时保持纯文本)。CLI 同源查询见 `changes list`(速查表见 `collector-cli changes list --help`)。
