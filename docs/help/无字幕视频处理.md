# 无字幕视频处理

视频没有字幕(UP 未传 CC、平台未生成 AI 字幕)时的圈定与兜底。三平台(B 站 / YouTube / 抖音)行为对齐;ASR 兜底当前覆盖 B 站与抖音。

相关:[[采集模型]]、[[标签体系]]、[[环境变量]]

## no-subtitle 标记(已就位)

采集确认无字幕时,**自动**打 `no-subtitle` 系统档标签:

```bash
pnpm cli videos list --tag no-subtitle          # 圈定所有无字幕视频
pnpm cli videos list --tag no-subtitle --source youtube
pnpm cli videos list --tag no-subtitle --source douyin
```

- 自动摘标:之后采到字幕轨(含 ASR 兜底转写入库)时自动摘掉
- 历史存量回填:`node scripts/backfill-no-subtitle-tags.mjs`(两平台)

## ASR 批量兜底(B 站 2026-08-26 起;抖音 2026-08-29 起)

`asr backfill` 把 no-subtitle 圈定的视频批量转写入库,`--source` 定平台;转写成功自动摘 no-subtitle 标(重跑自动跳过已完成,天然断点续跑)。

**B 站链路**:**CLI 圈定(server HTTP)→ B 站 playurl 拉音轨(移植扩展 wbi 签名)→ 本机 fireredasr-ui(FireRedASR-AED-L)转写 → 写回 `asr-zh-<引擎>` 轨**(如 `asr-zh-fireredasr-aed-l`,lan_doc 中文(ASR·引擎),origin='asr')。

**抖音链路**(无 cookie 依赖):**圈定 → 取入库 extra.play_uri 直构 snssdk 直链下载 mp4 → fireredasr 转写(内部抽音轨)→ 写回 `asr-zh-<引擎>` 轨**。

> 轨名按引擎派生(2026-08-29 起,server 从请求 engine 派生 lan;存量 `asr-zh` 轨由迁移 v19 按版本引擎改名):**不同引擎 → 不同轨并存**,web 视频详情的轨选择器直接切换比对多引擎版本;同引擎重跑同内容幂等去重不堆积。

```bash
# 预检圈定口径(不下载不转写)——两平台都先 dry-run 看清单
pnpm cli asr backfill --dry-run --size 5
pnpm cli asr backfill --dry-run --size 5 --source douyin

# 首跑 5 条实测速度(M4 实测 RTF≈0.2:1 小时音频约 12 分钟机时)
pnpm cli asr backfill --size 5
pnpm cli asr backfill --size 5 --source douyin

# 常用参数
pnpm cli asr backfill --size 20 --max-duration 900          # 只转 ≤15 分钟的视频
pnpm cli asr backfill --size 20 --page 2                     # 翻页继续
pnpm cli asr backfill --cookie-file ~/bili-cookie.txt        # 带 cookie(充电视频需要,仅 B 站)
```

- **前置**:collector-server 在跑(圈定/写回走 server HTTP);fireredasr-ui 在跑(`~/Local/fireredasr-ui`,`./run.sh start`)
- **cookie(仅 B 站必配)**：文本文件原样作 Cookie 头（`SESSDATA=xxx; ...`），从浏览器导出一次存本地；nav 取 wbi keys 即需登录态（匿名 nav -101，2026-08-26 实测），无 cookie 全批 need_login。也可用环境变量 `COLLECTOR_BILI_COOKIE_FILE`。抖音直链零 cookie
- **抖音 500MB 上限**:mp4 整段下载上传,超限跳过计 `video_too_large`(不重试——重试体积也不会变小),确需转写人工分段处理;`--max-duration` 先行控批量耗时
- **转写服务地址**:`--asr-url`(默认 `http://127.0.0.1:5079`);引擎标记 `--engine`(默认 `fireredasr-aed-l`,入 asr_engine 列兼定轨名 `asr-zh-<engine>`)
- **日志**:`[circle]/[bili]/[douyin]/[download]/[asr]/[submit]` 分步 stderr + 失败分类计数,失败不中断批次,汇总样例 vid。B 站分类:need_login / risk_control / no_audio / asr_error…;抖音分类:`missing_play_uri`(库内无直链,采集入库结构变化)/ `video_too_large` / `detail_fetch_error`(详情端点拉取失败)/ `download_http_XXX` / `truncated`(疑似片段拒入库)等
- **入库后**:asr-zh-<引擎> 轨在 web 视频详情/导出/`sub search`/bundle 中与普通轨同等可用;平台日后真出字幕时 asr 版本自动让位(versionPriority)

## 兜底路线全景

| 路线 | 状态 | 说明 |
|---|---|---|
| 服务端 ASR 批量转写(B 站) | ✅ `asr backfill` | 本机 fireredasr-ui + FireRedASR-AED-L,见上节 |
| 服务端 ASR 批量转写(抖音) | ✅ `asr backfill --source douyin` | 入库 play_uri 直构直链下载 mp4(零 cookie),同 fireredasr 转写 |
| 浏览器本地 Whisper 转写 | 🛌 休眠 | [apps/subtitle-extractor](../../apps/subtitle-extractor)(旁挂手动工具):依赖的外部仓库 voicetxt 已失源,扩展休眠保留不删 |
| YouTube 侧 ASR 兜底 | 📋 待议 | 需引入 yt-dlp(外部依赖)且英文/多语言宜换引擎(Whisper 系),另行决策 |
