# 无字幕视频处理

视频没有字幕(UP 未传 CC、平台未生成 AI 字幕)时的圈定与兜底。两平台(B 站 / YouTube)行为对齐。

相关:[[采集模型]]、[[标签体系]]

## no-subtitle 标记(已就位)

采集确认无字幕时,**自动**打 `no-subtitle` 系统档标签:

```bash
pnpm cli videos list --tag no-subtitle          # 圈定所有无字幕视频
pnpm cli videos list --tag no-subtitle --source youtube
```

- 自动摘标:之后采到字幕轨时自动摘掉
- 历史存量回填:`node scripts/backfill-no-subtitle-tags.mjs`(两平台)

## 兜底路线

| 路线 | 状态 | 说明 |
|---|---|---|
| 浏览器本地 Whisper 转写 | 🚧 旁挂手动工具 | [apps/subtitle-extractor](../../apps/subtitle-extractor):B 站音轨提取 → 浏览器本地 Whisper → SRT/VTT 导出。零后端、数据不出本机。**未集成入库链路**——转写产物暂无回流 bundle 的桥,导出后手动用 |
| 服务端 ASR 批量转写 | 📋 远期 | 对 `no-subtitle` 标圈定的视频批量转写;前置(no-subtitle 标记)已就位 |

> [!tip] extractor 的定位
> subtitle-extractor 是独立 MV3 扩展(transformers.js),不依赖 collector-server。当下用法:对少量重点视频手动转写,产物 SRT/VTT 自行保管。
