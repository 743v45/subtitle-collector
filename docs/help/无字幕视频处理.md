# 无字幕视频处理

视频没有字幕(UP 未传 CC、平台未生成 AI 字幕)时的圈定与兜底。两平台(B 站 / YouTube)行为对齐。

相关:[[采集模型]]、[[标签体系]]、[[环境变量]]

## no-subtitle 标记(已就位)

采集确认无字幕时,**自动**打 `no-subtitle` 系统档标签:

```bash
pnpm cli videos list --tag no-subtitle          # 圈定所有无字幕视频
pnpm cli videos list --tag no-subtitle --source youtube
```

- 自动摘标:之后采到字幕轨(含 ASR 兜底转写入库)时自动摘掉
- 历史存量回填:`node scripts/backfill-no-subtitle-tags.mjs`(两平台)

## ASR 批量兜底(B 站,2026-08-26 起)

`asr backfill` 把 no-subtitle 圈定的 B 站视频批量转写入库,链路:
**CLI 圈定(server HTTP)→ B 站 playurl 拉音轨(移植扩展 wbi 签名)→ 本机 fireredasr-ui(FireRedASR-AED-L)转写 → 写回 `asr-zh` 轨**(中文(ASR 转写),origin='asr',成功自动摘 no-subtitle 标——重跑自动跳过已完成,天然断点续跑)。

```bash
# 预检圈定口径(不下载不转写)
pnpm cli asr backfill --dry-run --size 5

# 首跑 5 条实测速度(M4 实测 RTF≈0.2:1 小时音频约 12 分钟机时)
pnpm cli asr backfill --size 5

# 常用参数
pnpm cli asr backfill --size 20 --max-duration 900          # 只转 ≤15 分钟的视频
pnpm cli asr backfill --size 20 --page 2                     # 翻页继续
pnpm cli asr backfill --cookie-file ~/bili-cookie.txt        # 带 cookie(充电视频需要)
```

- **前置**:collector-server 在跑(圈定/写回走 server HTTP);fireredasr-ui 在跑(`~/Local/fireredasr-ui`,`./run.sh start`)
- **cookie（**必配**）**：文本文件原样作 Cookie 头（`SESSDATA=xxx; ...`），从浏览器导出一次存本地；nav 取 wbi keys 即需登录态（匿名 nav -101，2026-08-26 实测），无 cookie 全批 need_login。也可用环境变量 `COLLECTOR_BILI_COOKIE_FILE`
- **转写服务地址**:`--asr-url`(默认 `http://127.0.0.1:5079`);引擎标记 `--engine`(默认 `fireredasr-aed-l`,入 asr_engine 列)
- **日志**:`[circle]/[bili]/[download]/[asr]/[submit]` 分步 stderr + 失败分类计数(need_login / risk_control / no_audio / asr_error…),失败不中断批次,汇总样例 vid
- **入库后**:asr-zh 轨在 web 视频详情/导出/`sub search`/bundle 中与普通轨同等可用;平台日后真出字幕时 asr 版本自动让位(versionPriority)

## 兜底路线全景

| 路线 | 状态 | 说明 |
|---|---|---|
| 服务端 ASR 批量转写(B 站) | ✅ `asr backfill` | 本机 fireredasr-ui + FireRedASR-AED-L,见上节 |
| 浏览器本地 Whisper 转写 | 🛌 休眠 | [apps/subtitle-extractor](../../apps/subtitle-extractor)(旁挂手动工具):依赖的外部仓库 voicetxt 已失源,扩展休眠保留不删 |
| YouTube 侧 ASR 兜底 | 📋 待议 | 需引入 yt-dlp(外部依赖)且英文/多语言宜换引擎(Whisper 系),另行决策 |
