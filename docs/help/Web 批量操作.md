# Web 批量操作

不开终端的批量动作:打标/摘标、合集采集、搜索采集、条件采集、创作者资料刷新。各自对应的 CLI 命令在各节标出。

## 视频库批量打标 / 摘标

对应 CLI `tags apply` / `tags remove`(档位语义见 [[标签体系]])。

- **勾选**:表头全选(仅当前页,支持半选态)+ 行勾选;**勾选不跨页**——翻页或改筛选后清空,跨页大批量走 CLI
- **打标**:选中后操作条输入标签名(中英文逗号分隔多个)+ 选档位(manual / batch / ai)→ 批量打
- **摘标**:输入标签名 + 选档位;选「全部档位」**先弹二次确认框**(删除不可撤销),指定档位直接删
- `system` 档(no-subtitle 等系统状态标)不在此操作,由采集链路自动打/摘

## 合集卡采集

对应 CLI `collect season`(见 [[采集合集与搜索]])。

视频属于合集时,视频详情页显示「合集」卡:点开展开全集——已入库行只展示徽章(不可勾,重采走刷新路径),未采行默认勾选、可再挑 → 点「采集勾选 (N)」批量建 B 站采集任务,进度在采集页任务列表看。

## 搜索采集卡

对应 CLI `collect search`(见 [[采集合集与搜索]])。

采集页「搜索采集」卡,右上角选模式:

- **快速搜索**(同步直连):选平台(B 站 / YouTube)+ 关键词 → 候选列表(标题 / 作者 / 播放·时长,带「已采」「已入库无字幕」徽章)→ 勾选 → 批量建采集任务
- 高级项随平台切换:B 站 = 分区 tid;YouTube = 排序 / 页数(1–5)/ 近 N 天(1–365)
- 搜索经扩展执行,**需桌面扩展在线**;报 503 时页面提示「扩展离线」——去浏览器扩展 popup 侧确认连接(见 [[排错]])

## 条件采集面板

模式切「条件采集」= CLI `collect find` 的后台任务化(B 站专属):关键词 + 页数 + 过滤旋钮(**最少 / 最多粉丝数、近几天内发布、分区 tid**,留空 = 不限)→ 提交为后台任务,进度卡轮询、跑完系统通知。

- 可勾「**命中候选自动建采集任务**」——不勾则只出候选清单,人工复核后再采
- 粉丝数读库内缓存,无缓存的候选保守保留并计 unknown,复核时留意

## 创作者「刷新资料」

创作者详情页「刷新资料」按钮 = CLI `upper-info refresh <mid>`:经扩展重拉 B 站空间信息(头像 / 签名 / 粉丝数等)回写。需桌面扩展在线;客户端页可见哪些客户端在线,见 [[客户端与任务派发]]。
