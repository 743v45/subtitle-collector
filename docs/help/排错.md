# 排错

症状 → 根因 → 处置。查不到再开诊断会话(工具日志看不清的,先修日志再跑,CLAUDE.md §9)。

相关:[[开始使用]]、[[客户端与任务派发]]、[[Docker 部署]]

## popup 显示未连接

按顺序查:

1. **server 起了吗**:`pnpm cli server ping`(或 `curl http://127.0.0.1:21527/ping`)
2. **popup 的 server URL 对吗**:默认 `ws://127.0.0.1:21527/ext`;改过 `COLLECTOR_PORT` 要同步改 URL
3. **设了 `COLLECTOR_TOKEN` 吗**:设了的话 URL 必须带 `?token=xxx`(popup 服务器配置里填完整 URL),见 [[环境变量]]

## 任务一直 pending 不跑

任务由**在线且开着任务派发**的客户端执行:

```bash
pnpm cli clients list                       # 看谁在线
pnpm cli clients task-dispatch <id> on      # 全被关了就没人接单
```

多机时任务派给开着的机器;全关留 pending。见 [[客户端与任务派发]]。

## 任务超时(抖音 / YouTube 整批「采集超时」)

YouTube / 抖音是窗口式超时:扩展后台开 tab 导航到视频页,持续无新进展满窗口时长才判超时(默认 45s),错误文案带平台前缀(如「抖音 采集超时(45s)」)。慢加载视频整批超时时,web 设置页「采集超时」卡片调大对应平台窗口(保存后对之后派发的任务生效,server 等回执预算自动联动,无需手动配)。分档语义见 [[采集模型]]。

## 抖音博主批量报「需登录」/ 列表为空

博主批量列表接口匿名态返回 200 空体(抖音 gating,非 4xx)——扩展把它识别为「需登录」一等错误。处理:在跑扩展的浏览器里登录 douyin.com 再展开。单视频采集匿名可用,不受影响。

## 抖音博主批量报「在线扩展版本均过低」/「扩展版本过旧」

博主展开(expand-douyin-upper)是扩展 0.1.25 新增能力,旧扩展不认识。多机同时在线时 server 只派给 ≥0.1.25 的机器;一台都不够新则报 503 并列出各端版本(如 `ext-A@0.1.18、ext-B@未知版本`)。处理:在版本落后的机器上重新构建并更新扩展(`pnpm build:ext` 后 chrome://extensions 刷新,以 popup 品牌头版本号核对),或在够新的机器上开着扩展再展开。报「扩展版本过旧,请更新扩展后重试」同理(回执侧同一分类)。

## 扩展 popup 闪烁 / 白屏死循环

CRXJS 已知坑:扩展 dev 端口漂移,把不一致端口烧进 dist。端口在 [vite.config.ts](../../apps/subtitle-collector/vite.config.ts) 用 `strictPort` 钉死为 **5174**(web 占 5173),**不要改**。中招了就重新 `pnpm build:ext` 再在 chrome://extensions 刷新。

## 采集报「解析失败 / 0 视频」

这类无上下文的失败**视为工具 bug,修的是日志而不是猜原因**(反爬?结构变了?):

- 工具的 `[fetch]/[parse]/[filter]` 分步 stderr 日志是否足够定位?不够先补日志(CLAUDE.md §9)
- 参考实现:[scripts/youtube-collect-videos.mjs](../../scripts/youtube-collect-videos.mjs) 的分步日志 + `pageDiag()` 页面特征输出

## SQLite 报错 / 库损坏

- **生产(Docker)**:禁 bind mount 是红线,只用 named volume,见 [[Docker 部署]];查库走 HTTP/CLI 或 `docker exec`,别碰文件
- 探活测不出坏页:`pnpm verify:deployed -- --db <路径>` 跑 `integrity_check`
- 开发期重置:`rm` 掉 db 文件重启 server(数据没了,仅限开发库)

## server 起停管理

```bash
pnpm cli server status     # online / DB / pid 文件 / 配置
pnpm cli server start      # 后台 detached,日志 .collector-server.log
pnpm cli server stop       # SIGTERM + 清 pid 文件
```

## 改了代码行为和文档对不上

help 中心与代码同步是纪律(CLAUDE.md §5):以代码 + `pnpm cli <cmd> --help` 为准,发现漂移顺手修页。
