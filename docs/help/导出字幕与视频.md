# 导出字幕与视频

单视频字幕导出与视频列表导出。批量打包给分析用走 [[导出分析原料包]]。

相关:[[全文检索字幕]]、[[检索视频库]]

## 字幕导出

```bash
# srt(默认),不指定轨/版本则取默认轨默认版本
pnpm cli export subtitle bilibili BV1xxxxxx

# 指定语言轨 + 格式 + 落盘
pnpm cli export subtitle bilibili BV1xxxxxx --track zh-Hans --sub-format vtt -o out.vtt

# YouTube
pnpm cli export subtitle youtube dQw4w9WgXcQ --sub-format txt
```

| 选项 | 说明 |
|---|---|
| `--track <lan>` | 指定字幕轨 lan(精确,如 `zh-Hans`) |
| `--version <id>` | 指定 subtitle_version id(**优先于 `--track`**) |
| `--sub-format <fmt>` | srt / vtt / txt / json,默认 srt |
| `-o, --output <file>` | 写文件;不指定则写 stdout |

> [!tip] 默认轨优先级
> CC 中文 > AI 中文 > 英文 > 其他;补翻过中文的视频默认轨是中文(见 [[补翻中文字幕]]),export 自动受益。

## 视频列表导出

过滤项与 `videos list` 完全一致(见 [[检索视频库]]),格式由全局 `--format` 控制:

```bash
pnpm cli export videos --creator "某UP" --format csv
pnpm cli export videos --has-subtitle --format ndjson > all.ndjson
```

格式:csv / ndjson / table。
