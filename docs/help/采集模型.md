# 采集模型

所有采集页的前置读物:数据怎么流、入口有哪几个、任务怎么跑。

## 数据流

```
浏览器(B站/YouTube/抖音 页面) ──MV3扩展──WS──▶ collector-server(21527) ◀──HTTP── 浏览器(web UI / CLI)
                                                     │
                                                     ▼
                                                SQLite (.db)
```

要点:**扩展在浏览器里 fetch 平台接口**,server 只是中转与存储。所以采集发生时必须有一个装了扩展的浏览器在线(CLI 下发的任务也是经 server 转给扩展执行)。抖音接口带页面签名、server 无法直连,采集一律由扩展后台开 tab 导航到视频页执行(navigate 模式)。

## 被动 vs 主动

| 方式 | 触发 | 说明 |
|---|---|---|
| 被动 | 打开 B 站视频页 | 扩展自动抽取字幕元信息入库,零操作(仅 B 站) |
| 主动 | CLI / popup / web 采集页 / 手机分享 | 显式指定目标,见下方五入口;YouTube / 抖音走扩展后台 tab 导航采集 |

| 入口 | 页面 | 说明 |

## 任务模型

- 主动批量采集 = **建任务**,server 自动串行执行,popup / web 任务行可见进度
- **单任务超时按平台分档**(web 设置页「采集超时」卡片可调,`settings.collect_timeout_ms` 三键):B 站是 server 等回执预算(默认 90s);YouTube / 抖音是扩展侧「无进展窗口」(默认 45s,持续无新进展才判超时,server 回执预算自动按窗口+135s 联动)——慢视频整批超时时调大对应平台窗口
- **幂等**:ingest 按 `body_hash` 去重,重复采集内容未变则零新增
- **刷新**:对已采视频重采,任务行显示「已刷新:新增 X 版 / 无新增」
- **重试并入原批次**:失败重试不另开新批,聚焦视图实时看
- **终态通知**:任务全部到终态时发浏览器系统通知(提交后切走标签页,跑完即被提醒)

## 无字幕怎么办

采集确认无字幕(UP 未传 CC 且平台未生成 AI 字幕)自动打 `no-subtitle` 系统标签圈定,兜底路线见 [[无字幕视频处理]]。
