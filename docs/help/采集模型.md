# 采集模型

所有采集页的前置读物:数据怎么流、入口有哪几个、任务怎么跑。

## 数据流

```
浏览器(B站/YouTube 页面) ──MV3扩展──WS──▶ collector-server(21527) ◀──HTTP── 浏览器(web UI / CLI)
                                                │
                                                ▼
                                           SQLite (.db)
```

要点:**扩展在浏览器里 fetch 平台接口**,server 只是中转与存储。所以采集发生时必须有一个装了扩展的浏览器在线(CLI 下发的任务也是经 server 转给扩展执行)。

## 被动 vs 主动

| 方式 | 触发 | 说明 |
|---|---|---|
| 被动 | 打开 B 站视频页 | 扩展自动抽取字幕元信息入库,零操作 |
| 主动 | CLI / popup / web 采集页 | 显式指定目标,见下方四入口 |

## 四个批量入口

| 入口 | 页面 | 说明 |
|---|---|---|
| UP 主批量 | [[批量采集 UP 主视频]] | 全量 / 增量 / 多 UP 巡检 |
| YouTube 频道批量 | [[采集 YouTube 频道]] | `@handle` 任意子页识别,全量分页 |
| 合集批量 | [[采集合集与搜索]] | `seasons_archives_list` 展开全集 |
| 搜索批量 | [[采集合集与搜索]] | 关键词 + 条件过滤出候选 |

## 任务模型

- 主动批量采集 = **建任务**,server 自动串行执行,popup / web 任务行可见进度
- **幂等**:ingest 按 `body_hash` 去重,重复采集内容未变则零新增
- **刷新**:对已采视频重采,任务行显示「已刷新:新增 X 版 / 无新增」
- **重试并入原批次**:失败重试不另开新批,聚焦视图实时看
- **终态通知**:任务全部到终态时发浏览器系统通知(提交后切走标签页,跑完即被提醒)

## 无字幕怎么办

采集确认无字幕(UP 未传 CC 且平台未生成 AI 字幕)自动打 `no-subtitle` 系统标签圈定,兜底路线见 [[无字幕视频处理]]。
