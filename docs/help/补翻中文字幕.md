# 补翻中文字幕

`translate` 三步工作流:给"有其他语言轨、但没有中文轨"的视频补一条 `zh-manual` 翻译轨。翻译由会话内大模型完成,系统只负责查缺口、取原料、写回。

相关:[[导出字幕与视频]](补翻后默认轨变中文,export 受益)

## 三步

```bash
# 1. 查缺口:哪些视频无中文轨(带各源语言行数)
pnpm cli translate pending
pnpm cli translate pending --from ai-en --creator "某UP"      # 细筛

# 2. 取逐行待翻文本(时间戳 + 原文)
pnpm cli translate source BV1xxxxxx
pnpm cli translate source BV1xxxxxx --from ai-en -o raw.txt   # 落盘喂给翻译

# 3. 会话内大模型翻译后,写回 zh-manual 轨
pnpm cli translate fill BV1xxxxxx <翻译结果文件>
```

## 写回规则

- **行数对齐校验**:翻译行数必须与源轨一致,不一致拒绝写入
- **时间轴从源轨拷贝**:不重打时间戳
- 轨道类型自动记为翻译轨(`--track-type 3` 可筛,见 [[检索视频库]])

## 效果

补翻后该视频**默认轨变中文**(默认轨优先级 CC 中文 > AI 中文 > 翻译中文 > 英文 > 其他):

- [[导出字幕与视频]] 直接导出中文
- [[全文检索字幕]] 默认搜到中文
- [[导出分析原料包]] 打包的是中文正文

> [!tip] `pending` 的排序
- 默认 `first_seen` 降序(最新入库在前),`--asc` 翻转;`--sort published_at` 按发布时间。
