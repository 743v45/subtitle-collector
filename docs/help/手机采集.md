# 手机采集

> Android 原生 app（[apps/collector-android](../../apps/collector-android)，Kotlin + Compose）：手机端随手采集与查询。server 侧零改动，任何已部署的 collector-server 直接可连。

## 装机

```bash
# 本机构建（需 JDK 21 + Android SDK，见下「开发」节）
cd apps/collector-android
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk

# 真机安装（USB 调试已开启）
adb install app/build/outputs/apk/debug/app-debug.apk
```

## 首启配置

1. 打开 app 自动进设置页；
2. **Server 地址**：collector-server 的访问入口（局域网部署形如 `http://192.168.x.x:21527`）；
3. **Token**：对应部署的 `COLLECTOR_TOKEN`——loopback 部署可不设，暴露部署（`0.0.0.0`）必设；
4. 点「测试连接」（会先保存当前输入再探测 `/ping`）→ ✓ 即通；
5. 「保存」回到提交页。

> 手机须与 server 网络可达（同一局域网 / 组网）。出门在外的公网通路未内置——真用后需要再评估（Tailscale 或反代，单独部署决策）。

## 分享采集（核心用法）

在 B 站 / YouTube App 里看到想采的视频：

1. 点系统分享菜单 → 选「**采集字幕**」；
2. app 打开**确认页**：本地预解析显示平台徽章 + 链接（预解析识别不出时也会显示原文，由 server 解析兜底）；
3. 点「**采集**」→ `POST /api/collect-tasks`（server 解析链接、短链展开、建任务并派发给浏览器扩展客户端执行）；
4. 成功视图显示任务号 → 「完成」退出。

同视频已有在途任务时 server 返回既有任务（不重复采集），确认页会明示。链接解析失败（非视频页/不支持的站）时 server 的 400 文案就地展示。

## app 内粘贴提交

提交页粘贴分享文本/链接 → 「提交采集」。输入框下方实时显示本地预解析结果（平台 + URL）；未识别出链接会提示，但提交仍由 server 做权威解析。

## 任务页

- 最近 50 条任务，前台 **2s 轮询**（与 web 采集页同频）；
- 状态徽章：排队中 / 采集中 / 成功 / 失败 / 受限（limited=字幕受限终态，可重试）；
- 失败行直接展示 server 错误文案；
- **重试**：failed/limited 行原地重置回 pending 重跑（不建新行）；在途/成功行不提供重试；
- **删除**：任意状态可删。

## 视频库 / 字幕查看

- 视频页：关键词搜索 + 平台过滤（全部/B站/YouTube），滚动到底自动加载下一页，行内显示封面/UP/时长/轨数；
- 点行进详情：元信息 + 「在原站打开 ↗」+ 轨道/版本切换（默认版本预选 ★）+ 字幕正文（`[分:秒]` 时间码行格式，与 bundle 正文一致）。

## 开发

```bash
cd apps/collector-android
./gradlew :app:assembleDebug        # 构建
./gradlew :app:testDebugUnitTest    # JUnit 单测（分享文本解析 / API 契约模型）
./gradlew :app:detekt               # 静态检查（ESLint 的原生等价物）
```

- 前置：**JDK 21** + **Android SDK**（`ANDROID_HOME` 或 `apps/collector-android/local.properties` 写 `sdk.dir=<SDK 根>`）；
- 工程纪律：四件套豁免（RULES §10 登记），gradle 任务**不进 `pnpm qa`**；涉 app 改动的提交 bump `versionCode`；
- `package.json` scripts 刻意用 `assemble`/`unit-test`/`lint` 命名（避开 build/test，防 turbo 误挂 gradle）。
