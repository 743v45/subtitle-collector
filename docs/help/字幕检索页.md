# 字幕检索页

web 里搜字幕正文:「那句『事务隔离』是哪个视频第几分钟说的」这类问题,不开终端直接查。CLI 同能力是 `sub search`(见 [[全文检索字幕]])。

相关:[[全文检索字幕]]、[[检索视频库]]、[[Web 导出与原料包]]

## 入口

侧栏「工作流 → 字幕检索」(`#/search`)。输入关键词(必填),回车或点「搜索」。

## 筛选项

| 项 | 说明 |
|---|---|
| 检索关键词 | 字幕正文子串匹配;勾「正则模式」后按 JavaScript 正则解析(如 `数据库|存储`) |
| 正则模式 | 关键词当正则源串;非法正则会在提交时报错,改写法即可 |
| 区分大小写 | 默认不区分 |
| 上下文(秒) | 命中片段前后扩展的时间窗,默认 10 秒 |
| 平台 / 创作者 | 缩小检索范围(平台下拉 / 创作者名模糊) |

## 结果怎么看

- 每个命中视频一张结果卡:标题(点击进视频详情)+ 语言徽章 + 创作者/发布日期 + 原站外链
- 片段行:`[分:秒]` + 命中原文(**命中词高亮**),下方「上下文」折叠展开前后文
- 数量上限(当前用 server 默认值):每视频最多 3 段、全局 30 段、最多 100 个视频
- 检索条件写 URL query,刷新/分享链接即还原;点「重置」清空条件

> [!tip] 搜完想拿全文?
> 结果卡点标题进视频详情 →「按轨导出」选轨与格式直接下载,见 [[Web 导出与原料包]]。

## 与 CLI 的对应

| web | CLI |
|---|---|
| 关键词 + 正则模式 | `pnpm cli sub search "数据库\|存储" --regex` |
| 区分大小写 | `--case-sensitive` |
| 上下文秒数 | `--ctx <秒>` |
| 平台 / 创作者 | `--source <src>` / `--creator <name>` |

CLI 还有 web 未暴露的进阶项:`--all-tracks`(搜所有轨,默认只搜默认轨)、`--tid`(分区预筛)、`--plain` / `--full`(输出形态),见 [[全文检索字幕]]。
