# 环境变量

只有 collector-server 读环境变量。完整默认值见 [apps/collector-server/.env.example](../../apps/collector-server/.env.example)。

## 部署五变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `COLLECTOR_PORT` | `21527` | HTTP + WS 监听端口 |
| `COLLECTOR_DB_PATH` | `./bilibili-collector.db` | SQLite 路径 |
| `COLLECTOR_TOKEN` | 空(无 token 模式) | 鉴权 token;设了之后扩展 URL 须带 `?token=xxx`、CLI 须带 Bearer |
| `COLLECTOR_HOST` | `127.0.0.1` | 监听地址;`0.0.0.0` 暴露部署时**必须**同时设 `COLLECTOR_TOKEN`(启动强校验) |
| `COLLECTOR_ALLOWED_HOSTS` | 空 | 显式放行非 loopback 的 Host/Origin,逗号分隔(如 `192.168.1.5,collector.local`) |

## 两种模式

**本地闭环(默认)**:`127.0.0.1` + 无 token,开箱即连,零配置。

**暴露部署(局域网 IP / 域名)**:

```bash
COLLECTOR_HOST=0.0.0.0 \
COLLECTOR_ALLOWED_HOSTS=192.168.1.5,collector.local \
COLLECTOR_TOKEN=<随机串> \
node --env-file=.env dist/main.js
```

生成 token:

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
```

## ASR 转写三变量

web 补翻页 ASR 卡与 `asr backfill` 的服务端转写装配,详见 [[补翻与转写]]:

| 变量 | 默认值 | 说明 |
|---|---|---|
| `COLLECTOR_ASR_BASE_URL` | `http://127.0.0.1:5079` | fireredasr 服务地址(OpenAI 兼容);容器部署访问宿主机服务用 `http://host.docker.internal:5079` |
| `COLLECTOR_BILI_COOKIE_FILE` | 空 | B 站 Cookie 文件路径(文本原样作 Cookie 头);B 站转写必配,抖音零 cookie |
| `COLLECTOR_ASR_ENGINE` | `fireredasr-aed-l` | 引擎标记,兼定字幕轨名 `asr-zh-<引擎>`(不同引擎各自成轨) |

## 改动会波及哪里

- **改 `COLLECTOR_PORT`** → 扩展 popup 里配置的 server URL 要同步改
- **设 `COLLECTOR_TOKEN`** → 扩展 server URL 须带 `?token=xxx`(popup 服务器配置里填完整 URL);CLI 请求须带 Bearer token

> [!warning] 为什么默认锁 loopback
> 防 DNS rebinding。不是"不能暴露",而是暴露必须显式声明(`ALLOWED_HOSTS`)+ 强制鉴权(`TOKEN`),两者启动时校验。

## 注意

当前代码直接读 `process.env`,**没有集成 dotenv**:

- 开发期:`COLLECTOR_TOKEN=xxx pnpm dev:server` 注入
- 生产:`node --env-file=.env dist/main.js`(Docker 部署由 compose 注入,见 [[Docker 部署]])
